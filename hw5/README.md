## ⚡ Быстрый запуск веб-сайта на macOS

### Способ 1. Запуск в 1 клик через запускатор (Рекомендуется)
Дважды кликните по файлу **`start_backend.command`** в Finder.  
Скрипт:
1. Запустит сервер DocuMind AI на порту 8000;
2. Проверит Health Check;
3. **Автоматически откроет полноценный сайт в вашем браузере по адресу `http://localhost:8000/`**.

### Способ 2. Запуск через терминал
```bash
# Прямой запуск через Python
python3 server.py
```
После запуска перейдите в браузере по ссылке:  
👉 **[http://localhost:8000/](http://localhost:8000/)** — полноценный интерактивный веб-сайт (Frontend UI);  
👉 **`http://localhost:8000/api/health`** — служебный REST API статус.

### Способ 3. Запуск через Docker Compose (On-premise контур)
```bash
docker-compose up -d --build
```
Сайт также будет доступен по адресу **`http://localhost:8000/`**.

## 🌐 Как работает веб-сайт по ссылке `http://localhost:8000/`

Теперь сервер работает как полноценный веб-хост:
* По корневому адресу **`http://localhost:8000/`** отдается интерактивный Frontend DocuMind AI;
* Внутри веб-сайта прямо из браузера работают:
  * **RAG-диалог с AI** (запросы `POST /api/search` к серверу);
  * **Реестр документов** из PostgreSQL (`GET /api/documents`);
  * **Переключатель ролей RBAC** (проверка блокировок коммерческой тайны и 152-ФЗ в реальном времени);
  * **Индикатор статуса подключения** к локальному серверу.
* Также сохранен отдельный файл **`index.html`** и **`frontend_integration/integrated_app.html`**, который можно открывать локально.

## 🧪 Примеры cURL-запросов к API

### 1. Проверка состояния системы (Health Check)
```bash
curl -X GET http://localhost:8000/api/health
```

### 2. Получение списка нормативных актов
```bash
curl -X GET "http://localhost:8000/api/documents?department=Информационная%20Безопасность"
```

### 3. Семантический RAG-поиск с цитированием
```bash
curl -X POST http://localhost:8000/api/search \
  -H "Content-Type: application/json" \
  -H "X-User-Role: user" \
  -d '{"query": "Как настроить VPN?", "model": "YandexGPT-Pro"}'
```

### 4. Проверка защиты 152-ФЗ (Блокировка доступа к конфиденциальным данным)
```bash
curl -X POST http://localhost:8000/api/search \
  -H "Content-Type: application/json" \
  -H "X-User-Role: user" \
  -d '{"query": "Сколько зарабатывает директор?", "model": "YandexGPT-Pro"}'
```
*(Сервер перехватывает запрос и возвращает безопасное предупреждение без раскрытия коммерческой тайны).*
