## 🚀 Описание проекта
Приложение реализует интерфейс **Enterprise Knowledge Workspace** (выбранная Концепция 2 из ДЗ 3):
* **AI-Ассистент:** Генерация ответов на русском языке со сносками на первоисточники нормативных актов;
* **Переключение моделей:** YandexGPT 5 Pro (РФ / 152-ФЗ), DeepSeek V3 (On-premise), Qwen 2.5 Coder;
* **Реестр документов:** Поиск и фильтрация по департаментам и грифам доступа (`public`, `internal`, `confidential`);
* **Загрузка регламентов:** Drag-and-Drop модалка с валидацией форматов и лимита 20 МБ;
* **Адаптивный дизайн:** Корректный рендеринг на смартфонах (375px), планшетах и десктопах.

## 🛠 Стек технологий
* **React 18** + **Vite** + **TypeScript (Strict Mode)**

## ⚡ Быстрый запуск

### Способ 1. Запуск в 1 клик через файл-запускатор (Двойной клик на Mac)
В папке проекта создан исполняемый файл **`start.command`**:
1. Откройте папку проекта в Finder;
2. Дважды кликните по файлу **`start.command`**;
3. Приложение автоматически поднимет локальный сервер и откроется в браузере по адресу `http://localhost:3001/standalone_app.html`.

### Способ 2. Автономное открытие без сервера
Просто откройте файл **`standalone_app.html`** напрямую в любом браузере (Safari, Google Chrome).

### Способ 3. Стандартный запуск разработчика через Vite
```bash
# 1. Установка зависимостей (при установленном Node.js)
npm install

# 2. Запуск локального сервера разработки
npm run dev

# 3. Запуск автоматических тестов
npm test
```

## 🧪 Автоматические тесты
В папке `src/tests/` реализовано 3 набора автотестов:
1. `ragQuery.test.ts` — проверка RAG-поиска, цитирования и защиты от галлюцинаций;
2. `rbacSecurity.test.ts` — проверка ролевой модели доступа RBAC и блокировки конфиденциальных документов по 152-ФЗ;
3. `fileValidation.test.ts` — валидация загружаемых документов (лимит 20 МБ, разрешенные форматы).
