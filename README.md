## 🚀 Быстрый запуск финального проекта (`hw6`)

Главный интерактивный стенд проекта расположен в папке **[`hw6/`](hw6/)**. Проект запускается автономно без внешних зависимостей:

### 1. В 1 клик на macOS (Рекомендуется):
Дважды кликните по файлу **`hw6/start_full_stack.command`** в Finder (или запустите `./hw6/start_full_stack.command` в терминале).

### 2. Через терминал:
```bash
# 1. Запуск 23 автоматических тестов
python3 -m unittest discover -s hw6/tests -p "test_*.py" -v

# 2. Старт сервера
python3 hw6/server.py
```

После старта откройте в браузере:  
👉 **[http://localhost:8000/](http://localhost:8000/)** — полноценный интерактивный веб-интерфейс DocuMind AI;  
👉 **[http://localhost:8000/api/health](http://localhost:8000/api/health)** — статус системного мониторинга и интеграций.

## 🎯 Интерактивный тур для защиты проекта (Что показать преподавателю в `hw6`)

DocuMind AI Enterprise доведен до уровня **завершенного программного продукта** (дипломный/курсовой проект), где комиссия может протестировать каждый модуль системы в живом интерфейсе:

1. **Закрытый контур Zero-Trust и авторизация (Welcome Gateway):**
   * Прямой гостевой доступ к базе регламентов закрыт (152-ФЗ РФ);
   * Самостоятельная регистрация заблокирована (`403 Forbidden`);
   * **Быстрый демо-вход в 1 клик под 4 корпоративными ролями:**
     * 👑 **`Администратор`** (`admin@documind.intra`) — доступ к админке сотрудников и сбросу демо-базы;
     * 🛡️ **`Офицер ИБ`** (`sec_officer@documind.intra`) — доступ к конфиденциальным регламентам, логам и ИИ-Лаборатории;
     * 👔 **`HR Руководитель`** (`manager@documind.intra`) — доступ к кадровым регламентам, отпускам и премиям;
     * 💻 **`Инженер (User)`** (`employee@documind.intra`) — базовый доступ; проверка перехвата коммерческой тайны.
2. **Семантический RAG-ассистент и Каталог из 30 бизнес-сценариев:**
   * Интерактивный каталог из **30 готовых промптов по 6 направлениям** (ИБ и пароли, Кадры и отпуска, Финансы и командировки, IT и разработка, Юридический комплаенс, Стресс-тесты 152-ФЗ / Prompt Injection);
   * Клик по найденной цитате открывает Slide-over панель с полным текстом регламента и **ярко-желтой подсветкой** найденного фрагмента;
   * Кнопка **«Инспектор чанков»** — визуализация разбиения текста, перекрытий (overlap) и весов символьных n-грамм pgvector;
   * **Drag & Drop загрузка:** перетаскивание любого файла (`.txt`, `.md`, `.json`, `.csv`) моментально индексирует его на лету.
3. **🛡️ ИИ-Лаборатория: 152-ФЗ, DLP, RAG Triad & Граф знаний (вкладка «Лаборатория»):**
   * **DLP-Песочница:** Детекция и маскирование паспортов РФ, СНИЛС, карт МИР, секретов в 3 режимах (Audit, Masking, Quarantine);
   * **Матрица 8 мер ФСТЭК России № 21 (УЗ-1/УЗ-2):** Аудит обязательных мер защиты ИСПДн + **кнопка генерации официального Акта соответствия ФСТЭК** с гербом, подписями комиссии и печатью;
   * **RAG Triad & LLM Benchmarking:** KPI метрики Faithfulness (94.2%), Answer Relevance (91.8%), Context Recall (89.4%), A/B таблица моделей и запуск стресс-теста на 10 сценариях в реальном времени;
   * **Canvas Граф знаний:** 31 узел (5 хабов + 25 документов + ядро), 41 семантическая связь, вращающийся радарный луч, зум, панорамирование и поиск.
4. **Реестр нормативных документов предприятия:**
   * **25 утвержденных регламентов** по 5 департаментам (ИБ, IT, Кадры, DevOps, Финансы) с фильтрацией и полнотекстовым чтением.
5. **Администрирование сотрудников (только для роли Admin):**
   * Создание сотрудников с солением `SHA-256` (16 байт индивидуальной соли);
   * Моментальная блокировка/разблокировка учетных записей и аннулирование активных сессий;
   * Программная защита системного администратора от блокировки;
   * Кнопка сброса демо-базы в эталонное состояние.
6. **Биллинг и эквайринг ЮKassa:**
   * Оформление Enterprise-лицензии с QR-кодом;
   * Интерактивный эмулятор входящих Webhook (`payment.succeeded`, `payment.canceled`) со сверкой криптографической подписи **HMAC-SHA256** и живой историей транзакций.
7. **Observability, RFC 5424 Логи и AI-Аудитор:**
   * Мониторинг 5 стадий CI/CD пайплайна GitHub Actions;
   * Живой поток структурированных логов RFC 5424 (ALL, INFO, WARN, ERROR);
   * Встроенный AI-аудитор: анализ инцидентов и выявление аномалий безопасности в 1 клик.
8. **CI/CD Пайплайн (GitHub Actions):**
   * 5 успешно пройденных стадий: Quality Gate (Ruff/Flake8), Automated Tests (23 unit-теста), Security Audit (Bandit SAST), Docker Build, Continuous Deployment.
