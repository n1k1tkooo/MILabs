## 🚀 Быстрый запуск финального проекта (ДЗ 6)

Главный интерактивный стенд проекта расположен в папке **[`hw6/`](hw6/)**. Проект запускается локально без необходимости настройки сторонних баз данных или облачных API-ключей:

```bash
# 1. Перейдите в папку финального проекта
cd hw6

# 2. Запустите автоматический скрипт тестирования и старта (macOS)
./start_full_stack.command
```

Или классическим способом через терминал:
```bash
# Запуск 12 тестов
python3 -m unittest discover -s hw6/tests -v

# Старт сервера
python3 hw6/server.py
```

После старта перейдите в браузере по адресу:  
👉 **[http://localhost:8000/](http://localhost:8000/)** — полноценный интерактивный веб-интерфейс DocuMind AI;  
👉 **[http://localhost:8000/api/health](http://localhost:8000/api/health)** — статус системного мониторинга и интеграций.

## 🎯 Что преподаватель может проверить на защите в `hw6`

1. **Интеллектуальный RAG-поиск:** задать вопрос по регламентам («Как настроить VPN?», «Сколько дней учебный отпуск?») — получить ответ со скором косинусного сходства и цитатой.
2. **Просмотр регламентов с подсветкой цитат:** кликнуть на найденную цитату — откроется Slide-over панель с полным текстом регламента и **ярко-желтой подсветкой** найденного фрагмента.
3. **Инспектор векторов pgvector:** нажать кнопку *«Инспектор чанков»* — изучить нарезку текста с перекрытием, веса токенов и n-граммы.
4. **Drag & Drop загрузка файлов:** загрузить свой текстовый документ (`.txt`, `.md`, `.json`, `.csv`) — система мгновенно чанкует его, индексирует и находит ответы по новому документу на лету.
5. **Комплаенс 152-ФЗ РФ и ролевая безопасность:** спросить в роли *«Сотрудник»* о зарплатах руководства — шлюз безопасности заблокирует запрос и занесет инцидент в лог RFC 5424. Сменить роль на *«Офицер ИБ»* — доступ будет предоставлен.
6. **Живая аналитика (Chart.js):** графики распределения базы знаний по отделам и соотношение разрешенных/заблокированных запросов.
7. **CI/CD пайплайн:** перейдите во вкладку [GitHub Actions](https://github.com/n1k1tkooo/MILabs/actions) для проверки 5 успешно пройденных стадий (Quality Gate, Automated Tests, Security Audit Bandit, Docker Build, Continuous Deployment).
